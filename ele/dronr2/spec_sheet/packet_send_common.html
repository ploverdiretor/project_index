ESP-NOW パケット定義仕様書【送信・共通編】

ドローン側から自律送信されるデータ、および調整時に双方向でやり取りされる共通構造体の定義です。

1. リアルタイム機体テレメトリパケット (0x7A7A7A7A)

ドローンの現在の相対姿勢オイラー角と、現在の目標角度をコントローラーに送信します（100Hz周期）。ドローン ➔ コントローラー

  • 判定基準： 先頭4バイトが 0x7A7A7A7A
オフセット (Byte) 変数名 データ型 仕様・備考（受信側で戻すべきスケール）
0 〜 3 packetHeader uint32_t 固定ヘッダー。0x7A7A7A7A
4 〜 5 yaw int16_t 現在の機体のYaw角 (度×100) ➔ 100.0f で割って復元
6 〜 7 pitch int16_t 現在の機体のPitch角 (度×100) ➔ 100.0f で割って復元
8 〜 9 roll int16_t 現在の機体のRoll角 (度×100) ➔ 100.0f で割って復元
10 〜 11 target_yaw int16_t 現在の機体の目標Yaw角 (度×100) ➔ 100.0f で割って復元
12 〜 13 target_pitch int16_t 現在の機体の目標Pitch角 (度×100) ➔ 100.0f で割って復元
14 〜 15 target_roll int16_t 現在の機体の目標Roll角 (度×100) ➔ 100.0f で割って復元

2. センサー校正ステータスパケット (0x7C7C7C7C)

校正中および完了時に、各センサーのキャリブレーション状況をリアルタイム送信します。ドローン ➔ コントローラー

  • 判定基準： 先頭4バイトが 0x7C7C7C7C (データ長 8 Byte)
オフセット (Byte) 変数名 データ型 仕様・進捗ステータス値の意味
0 〜 3 packetHeader uint32_t 固定ヘッダー。0x7C7C7C7C
4 sys uint8_t システム全体の校正状態 (0 〜 3 / 3で完了)
5 gyro uint8_t ジャイロセンサーの校正状態 (0 〜 3 / 3で完了)
6 accel uint8_t 加速度センサーの校正状態 (0 〜 3 / 3で完了)
7 mag uint8_t 地磁気センサー状態 (0〜3)。フラッシュ記憶・復元完了時は 0xFF

3. 共通 PIDパラメータパケット (双方向構造体)

ゲインの「上書き送信」および「読み出し返送」で相互に利用されるパック化された構造体です。双方向通信

  • 判定基準： データ長 48 Byte ── かつ __attribute__((packed)) 属性必須
オフセット (Byte) 変数名 データ型 対象軸 ＆ 内部スケーリング仕様
0 〜 3 pitch_outer_p int Pitch軸 外側姿勢 Pゲイン (内部で / 100.0f)
4 〜 7 pitch_inner_p int Pitch軸 内側角速度 Pゲイン (内部で / 100.0f)
8 〜 11 pitch_inner_i int Pitch軸 内側角速度 Iゲイン (内部で / 100.0f)
12 〜 15 pitch_inner_d int Pitch軸 内側角速度 Dゲイン (内部で / 100.0f)
16 〜 19 roll_outer_p int Roll軸 外側姿勢 Pゲイン (内部で / 100.0f)
20 〜 23 roll_inner_p int Roll軸 内側角速度 Pゲイン (内部で / 100.0f)
24 〜 27 roll_inner_i int Roll軸 内側角速度 Iゲイン (内部で / 100.0f)
28 〜 31 roll_inner_d int Roll軸 内側角速度 Dゲイン (内部で / 100.0f)
32 〜 35 yaw_outer_p int Yaw軸 外側姿勢 Pゲイン (内部で / 100.0f)
36 〜 39 yaw_inner_p int Yaw軸 内側角速度 Pゲイン (内部で / 100.0f)
40 〜 43 yaw_inner_i int Yaw軸 内側角速度 Iゲイン (内部で / 100.0f)
44 〜 47 yaw_inner_d int Yaw軸 内側角速度 Dゲイン (内部で / 100.0f)
