ESP-NOW パケット定義仕様書【受信・コマンド編】

コントローラーから送信され、ドローン側が受信・処理するパケットおよび各種制御コマンドの定義です。

1. フライト操作パケット (0x7B7B7B7B)

操縦スティックの入力値をドローンへリアルタイムに伝達します。コントローラー ➔ ドローン

  • 判定基準： データ受信長 20 Byte ── かつ先頭4バイトが 0x7B7B7B7B
オフセット (Byte) 変数名 データ型 仕様・内部スケーリング
0 〜 3 packetHeader uint32_t 識別用ヘッダー。固定値 0x7B7B7B7B
4 〜 7 throttle int スロットル操作量 (0 〜 1000)
8 〜 11 pitch int ピッチ操作量 (-1000 〜 1000) ➔ 内部で最大±30度(ラジアン)に変換
12 〜 15 roll int ロール操作量 (-1000 〜 1000) ➔ 内部で最大±30度(ラジアン)に変換
16 〜 19 yaw int ヨー操作量 (-1000 〜 1000) ➔ 内部で最大±30度(ラジアン)に変換

2. モーターテスト用個別パケット (構造体 message)

各調整用スライダーから直接4chモーターを個別に回すためのデータです。コントローラー ➔ ドローン

  • 判定基準： データ受信長 = 16 Byte (識別ヘッダーなし、サイズで判定)
オフセット (Byte) 変数名 データ型 仕様・制限
0 〜 3 sliderValue[0] int モーター1駆動値 (0 〜 1000) ※10以下は停止、最大50%出力に安全制限
4 〜 7 sliderValue[1] int モーター2駆動値 (0 〜 1000) ※10以下は停止、最大50%出力に安全制限
8 〜 11 sliderValue[2] int モーター3駆動値 (0 〜 1000) ※10以下は停止、最大50%出力に安全制限
12 〜 15 sliderValue[3] int モーター4駆動値 (0 〜 1000) ※10以下は停止、最大50%出力に安全制限

3. システム制御コマンド (単発4バイトパケット)

特定のボタンを押した際に、1回だけ送信される4バイト固定のシステム要求です。コントローラー ➔ ドローン

ヘッダー値 (Hex) コマンド名 ドローン側の内部処理動作
0x7C7C7C7C センサー校正開始 モーター出力を即時遮断。BNO055キャリブレーション処理に移行。
0x7F7F7F7F PIDパラメータ読込 現在の機体内のPIDパラメータ(計12個)をコントローラーへ即時返送。
0x79797979 機体姿勢リセット 現在の物理的な傾きを「新しい水平基準面(q_reference)」として記憶。
